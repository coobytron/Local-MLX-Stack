Rules of thumb

Five habits that save time

One file, one task, one run for OpenCode. Split big jobs.
Never trust the model's summary. Open the file or run the check.
Always use the 32k model for OpenCode: stack setup once.
Give the Pipeline a project folder, or it invents files.
Benchmark three times. One run can mislead.
